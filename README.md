# ai_chat_mobile

Cross-platform mobile AI chat app (Android + iOS). Built on Flutter, backed entirely by Supabase (Auth, Postgres with RLS, Edge Functions). The Anthropic Claude API is called only from a Supabase Edge Function — never from the mobile client.

See [`Architecture.md`](./Architecture.md) for the architecture and conventions.
